    Register the server with query()

    The workshop above calls the tool directly. This optional path starts a real Claude query and lets the agent discover the same capability. 

    const server = createCourseServer();
const q = query({
  prompt,
  options: {
    tools: [],
    mcpServers: { course: server },
    allowedTools: ['mcp__course__lookup_lesson']
  }
});

    The configuration key course determines the namespace. The hosted server’s descriptive name is course-catalog. The full example also sets a permission mode, limits, and cleanup.

    Set ANTHROPIC_API_KEY in the server .env and restart to enable real agent queries. The local tool workshop needs no key.

            Each name is checked against the installed SDK at runtime. The status notes follow the
            course guide and the matching 0.3.310 declarations.
          
    
        
    
        
    
          
        
    
        
    
        
    
          Preparation is a separate lifecycle
          
    
            startup() returns a WarmQuery for a known session; its
            query(prompt) sends work later. Alpha prewarm() returns a
            parked SpareProcess that is claimed for a session later. These are
            different handles.
          
    
          
    
            The snippets explain the APIs; this page does not execute preparation or claim a latency
            improvement. See src/examples/preparation.ts for compile-checked entry
            points.
